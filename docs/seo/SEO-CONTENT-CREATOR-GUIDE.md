## Guidelines for Content Creators

### ✅ DO Use These Keywords Naturally

**Example 1: Hardware Description**
```
❌ BAD: "We make ultra-low power edge hardware and ultra-low power edge hardware 
for edge AI integration."

✅ GOOD: "Our ultra-low power edge hardware enables on-device intelligence 
and edge AI integration for sustainable IoT ecosystems."
```

**Example 2: Service Description**
```
❌ BAD: "We offer zero-trust IoT security and zero-trust security solutions."

✅ GOOD: "Ionity provides zero-trust IoT security frameworks that seamlessly 
integrate with cloud-to-edge continuity platforms."
```

### ❌ DON'T Do This

- **Keyword Stuffing:** Don't repeat keywords unnaturally
- **Forced Integration:** Don't make sentences awkward to fit keywords
- **Irrelevant Usage:** Don't use "Generative AI" if not relevant to topic
- **Outdated Terms:** Stop using "legacy" terms when trending ones apply

## Guidelines for Developers

### Meta Tags Template

When creating new HTML pages, use this template:

```html
<!-- Page-Specific Example: New "Edge AI Integration" Page -->
<title>Ionity | [PRIMARY KEYWORD] for [USE CASE] | Antwerp Designs</title>
<meta name="description" content="[Company] [VERB] [PROBLEM SOLVED]. 
[SOLUTION FEATURES] with [PRIMARY + SECONDARY KEYWORDS]. 
[LOCATION/UNIQUE VALUE PROP].">
<meta name="keywords" content="PRIMARY, SECONDARY, TERTIARY, RELATED, BRAND, LOCATION">
```

**Filled Example:**
```html
<title>Ionity | Edge AI Integration for Industrial IoT | Antwerp Designs</title>
<meta name="description" content="Ionity enables edge AI integration for real-time 
industrial IoT processing. Ultra-low power edge hardware with on-device AI orchestration 
for sustainable ecosystems in South Africa.">
<meta name="keywords" content="Edge AI Integration, On-device Intelligence, 
Industrial IoT, Ultra-Low Power Hardware, Energy-Efficient Computing, Ionity, South Africa">
```

### Schema.org Implementation

Add this to organization pages:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Ionity",
  "url": "https://www.ionity.today",
  "knowsAbout": [
    "Edge AI Integration",
    "[YOUR PRIMARY KEYWORD]",
    "[YOUR SECONDARY KEYWORD]"
  ]
}
</script>
```

## Common Mistakes to Avoid

### ❌ Mistake 1: Keyword Stuffing
```
WRONG: "Edge AI is the best solution for edge AI needs. Our edge AI 
solutions provide edge AI capabilities for edge AI integration."

RIGHT: "Our edge AI solutions provide on-device intelligence for 
real-time processing capabilities."
```

### ❌ Mistake 2: Ignoring Context
```
WRONG: "This blog about SCADA systems includes: Edge AI Integration, 
Digital Twin Architecture, Zero-Trust IoT Security" (no natural connection)

RIGHT: "This guide covers SCADA modernization through edge AI integration 
and digital twin architecture for predictive maintenance."
```

### ❌ Mistake 3: Abbreviating Keywords
```
WRONG: "Our PdM solution uses DTA with ZT security"
RIGHT: "Our Predictive Maintenance system uses Digital Twin Architecture 
with Zero-Trust IoT Security"
```

### ❌ Mistake 4: Using Outdated Terminology
```
WRONG: "Our IoT system provides cloud computing and mobile access"
RIGHT: "Our sustainable IoT ecosystem provides cloud-to-edge continuity 
with on-device intelligence"
```

## Publishing Checklist

**Before launching any new content:**

1. **SEO Meta Tags**
   - [ ] Title includes primary keyword (60 chars max)
   - [ ] Description includes primary + secondary keyword
   - [ ] Keywords list populated (10-15 terms)

2. **Header Structure**
   - [ ] H1 includes golden phrase or primary keyword
   - [ ] H2s organized with secondary keywords
   - [ ] Natural, clear hierarchy

3. **Keyword Distribution**
   - [ ] Primary keyword appears in: title, H1, intro, conclusion
   - [ ] Secondary keywords in H2 sections
   - [ ] Natural language (no stuffing)
   - [ ] 1-2% keyword density

4. **Internal Linking**
   - [ ] Links to related pages using keyword anchor text
   - [ ] At least 3-5 internal links per 1000 words
   - [ ] Links to product/service pages where relevant

5. **Schema/Structured Data**
   - [ ] Organization schema present
   - [ ] BreadcrumbList implemented
   - [ ] Product/Service schema (if applicable)
   - [ ] Validated with schema.org tools

6. **CMS/File Management**
   - [ ] File naming includes primary keyword (e.g., `edge-ai-integration.html`)
   - [ ] URL slug is SEO-friendly and keyword-relevant
   - [ ] Images have proper alt text with keywords
   - [ ] Mobile responsive design confirmed
