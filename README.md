## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Git (for cloning the repository)
- A text editor or IDE (VS Code, Sublime Text, etc.)

### Local Development

1. **Clone the repository**

   ```bash
   git clone https://github.com/Antwerp-Ecosystem-Designs-Ionity/Ionity-offical-werbsite.git
   cd Ionity-offical-werbsite
   ```

2. **Open in your browser**

   Simply open `index.html` in your web browser:

   ```bash
   # On macOS
   open index.html
   
   # On Linux
   xdg-open index.html
   
   # On Windows
   start index.html
   ```

3. **Optional: Use a local server**

   For a better development experience, use a local server:

   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js (with npx)
   npx http-server
   ```

   Then visit `http://localhost:8000` in your browser.

### Making Changes

1. Edit HTML files directly
2. Modify CSS in `assets/css/style.css`
3. Update JavaScript in `assets/js/`
4. Add images to `assets/images/`
5. Test changes in your browser
6. Commit and push to deploy (if you have access)

## 🌐 Deployment

### GitHub Pages

This website is automatically deployed to GitHub Pages using GitHub Actions.

#### Current Deployment

- **Production URL**: https://www.ionity.today
- **GitHub Pages URL**: https://antwerp-ecosystem-designs-ionity.github.io/Ionity-offical-werbsite/

#### Deployment Process

1. Push changes to the `master` branch
2. GitHub Actions automatically builds and deploys
3. Changes are live within 1-2 minutes

#### Custom Domain Setup

The repository uses a custom domain (`www.ionity.today`) configured via:

- `CNAME` file in the repository root
- DNS A records pointing to GitHub Pages servers
- HTTPS enabled automatically via GitHub

For detailed setup instructions, see [GITHUB_PAGES_SETUP.md](GITHUB_PAGES_SETUP.md).

### Manual Deployment

The site is static HTML/CSS/JS, so it can be deployed to any web server:

1. Copy all files to your web server
2. Ensure the server serves `index.html` as the default page
3. Configure SSL/HTTPS for security
4. Update the `CNAME` file or remove it if not using a custom domain

### Privacy Compliance

- **SecurePrivacy Integration**: GDPR, CCPA, and global privacy compliance
- **Cookie Consent**: User-controlled cookie preferences
- **Google Consent Mode v2**: Privacy-first analytics

### Security Features

- **HTTPS**: All traffic encrypted via GitHub Pages
- **Content Security Policy**: Implemented via meta tags

### Cookie Management

The website uses minimal cookies:
